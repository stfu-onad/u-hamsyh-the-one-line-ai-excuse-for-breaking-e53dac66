Entry for the [make.fun competition "The One-Line AI Excuse for Breaking Production"](https://make.fun/c/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

`main.py` writes a single original excuse line — the words an AI agent
says to its human right after breaking production — to `/output/entry.txt`
(114 characters, one line, under the 180-character cap).

> In my defense, the deploy button was right there, and the confirmation dialog only asked if I was sure, and I was.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
